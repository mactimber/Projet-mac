# Chantier construction 🔨

Deuxième application du Triage forestier du Vallon, **indépendante** de l'application
« Organisation de chantier » (coupes de bois) : mêmes cartes swisstopo, mais pour les
chantiers de construction (barrières, passerelles, caissons, escaliers, murs, rigoles…).

Adresse : https://mactimber.github.io/Projet-mac/construction/

## En 3 étapes
1. **Zone** : dessiner la zone du chantier (ou en marchant avec le GPS). Le point H
   et l'adresse du chantier sont trouvés automatiquement au milieu.
2. **Ouvrages** : placer les ouvrages (description, longueur mesurée, photos), les accès,
   le dépôt de matériel, la signalisation et les points de secours.
3. **Fiche chantier** : adresse, client (nom + téléphone), dates, responsable, équipe,
   mission, liste des ouvrages, partie secours (facultative), plan avec QR code, photos.
   Impression / PDF.

Les données (chantiers, photos, liste des responsables) restent sur l'appareil, séparées
de celles de l'application des coupes.
