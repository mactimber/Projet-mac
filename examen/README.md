# Dossier de coupe · E17 (Vaud) 🌲

Copie **indépendante** de la version vaudoise, pour le module E17 du brevet de contremaître.

Mêmes étapes (parcelle, symboles, fiche de secours), plus le bouton **📄 Dossier Word** à l'étape 3 :
il crée un fichier `.docx` pré-rempli avec les données du chantier, à compléter dans Word :

1. Description du chantier · 2. Méthodes de travail · 3. Analyse des risques ·
4. Prescriptions et mesures de sécurité · 5. Ordre de travail · 6. Qualification des collaborateurs
et des entrepreneurs · 7. Programme des travaux · 8. Coordination · 9. Normes de sécurité ·
10. Organisation des secours · 11. Estimation des coûts · Annexe : plan de coupe (image, légende, QR code).

Adresse : https://mactimber.github.io/Projet-mac/examen/

Les chantiers sont enregistrés séparément ; une copie de secours des autres versions peut être
importée (« Récupérer une copie »).
